# Release Notes — 2.0.1

App Store Connect의 "이 버전에서 업그레이드된 사항"에 붙여넣는 문구입니다.

## English (U.S.)

```
Stability update for YOGO 2.0.

• Fixed a crash when switching dates on the Home screen
• Fixed the intro screens not displaying correctly
• Smoother bottom sheets with drag-to-close
• A cleaner, full-width calendar in the schedule search
• Minor layout and alignment fixes

Thanks for using YOGO!
```
